## 🚀 Projects

### 1. ⚾️ Monte Carlo Baseball Analytics App
**Full-stack web application for evaluating MLB players using probabilistic simulation instead of single-season statistics.**

> **Project Details**  
> This project analyzes St. Louis Cardinals players by simulating many possible seasons using Monte Carlo methods. Repeatedly generating full 500 plate-appearance seasons from real batting probabilities, the application captures statistical uncertainty, performance variability, and risk. The results are summarized using statistical measures such as expected value and volatility, and visualized through interactive charts so that users can compare players side by side using distributions instead of single-point estimates.

> **Tech Stack**  
> - **Frontend:** React, JavaScript, Chart.js  
> - **Backend:** Flask (Python), REST APIs  
> - **Database:** MySQL  
> - **Deployment:** AWS EC2

📎 **Detailed Implementation:** https://github.com/wonjun0608/monte-carlo-baseball-simulator

### 4. 📡 Embedded Distance Display System
**Embedded system integrating sensing, control, and communication on an Arduino microcontroller.**

> An embedded systems that measures distance using an ultrasonic sensor and displays the results in real time through physical hardware. The system runs on an Arduino and is structured so that sensing, user input, display updates, and serial communication can operate at the same time without blocking the main control loop. Distance values are shown using a servo driven analog dial and an LED bar graph with adjustable brightness.

> **Tech Stack**  
> - **Embedded:** Arduino, ultrasonic sensor, servo motor, PWM-controlled LEDs  
> - **Software:** C, Java  
> - **Concepts:** Finite State Machines (FSMs), non-blocking event-driven design, serial communication  

📎 **Detailed Implementation:** https://github.com/wonjun0608/embedded-distance-display-system
