## 🚀 Projects

#### ⚾️ Monte Carlo Baseball Analytics Web App
**Full-stack web application for evaluating MLB players using probabilistic simulation instead of single-season statistics.**

> **Project Details**  
> This project models MLB player performance using Monte Carlo simulation to capture uncertainty, variability, and risk in season-level outcomes.  
> Instead of treating historical batting statistics as fixed values, the backend simulates hundreds of possible 500 plate-appearance seasons using real batting probabilities stored in a MySQL database.
>
> From the simulated outcomes, the system computes expected value (mean performance), volatility (standard deviation), and risk-adjusted metrics.  
> A React-based frontend visualizes these results interactively, allowing users to explore both average performance and statistical dispersion.
>
> The application supports side-by-side player comparison, where each player is simulated independently and evaluated using the same statistical framework.  
> Multiple visualization types—including histograms, expected value convergence plots, risk–return scatter plots, and radar charts—are used to highlight performance consistency, upside, and risk.

> **Tech Stack**  
> - **Frontend:** React, JavaScript, Chart.js  
> - **Backend:** Flask (Python), REST APIs  
> - **Database:** MySQL  
> - **Deployment:** AWS EC2
